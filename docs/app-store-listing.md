## 4. 描述（4000 字以内）

生活不总是一帆风顺，但每一天都值得被记录。

「今日微笑」是一款极简情绪打卡 App。每天花 30 秒，记录今天你笑了吗——笑了，写下一个让你开心的理由；没笑，也没关系，觉察本身就是一种温柔。

**为什么你需要它？**

- 看见情绪的变化：日历视图帮你回顾每月的微笑轨迹，那些低落的日子，回头看可能只是一个小坎。
- 坚持的力量：连续打卡统计让你直观看到自己的坚持，微笑率帮你了解自己的情绪模式。
- 不评判，只记录：我们不对你的情绪做任何评价。笑了很好，没笑也是真实的你。

**核心功能：**

- 每日一键打卡，记录笑了 / 没笑，附上原因和照片
- 日历视图，按月份回顾情绪轨迹，标记每一天
- 微笑统计，总打卡天数、连续打卡、微笑率一目了然
- 每日提醒，自定义时间，不错过每一次记录
- 照片记录，为每一天的心情附上一张画面
- 数据完全属于你，支持云端同步，换手机不丢失

**我们相信：**

关注情绪是善待自己的开始。无论今天笑了还是没笑，都值得被看见。
