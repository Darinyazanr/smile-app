### 为什么「今日微笑」与众不同？

**📦 极致简约**

只做一件事：记录你今天笑了没。不需要写长篇日记，不需要选复杂的情绪标签。一个按钮，两种状态，这就是全部。日历视图自动汇总，微笑统计一目了然——简单到你可以用一辈子。

**🔒 隐私优先，数据只属于你**

我们不收集你的个人信息，不追踪你的使用行为，不出售任何数据。你的打卡记录只存在你手机本地，没有任何数据上传到服务器。没有第三方分析工具，没有广告 SDK，没有埋点统计。

**你的手机，你的数据，你的情绪。仅此而已。**

---

### 核心功能

- **一键打卡** — 打开 App，点一下，完成。支持附上简短原因和照片，但绝不强制。
- **日历回顾** — 按月查看你的微笑轨迹，那些笑了和没笑的日子，一目了然。
- **微笑统计** — 总打卡天数、连续打卡、微笑率，三个数字看清你的情绪模式。
- **每日提醒** — 自定义时间推送，轻触直达打卡页面。推送完全本地化，无需联网。
- **纯本地存储** — 所有数据仅保存在你的手机上，绝不上传服务器。卸载即彻底消失，换手机不留痕迹。

## 9. 快速上架检查清单

- [ ] 在 Mac 上安装 `eas-cli`：`npm install -g eas-cli`
- [ ] 登录 Expo 账号：`eas login`
- [ ] 创建 `client/.env`（内容见上方第 1 节）
- [ ] 运行 `eas build --platform ios --profile production`
- [ ] 将生成的 `.ipa` 通过 Transporter 上传到 App Store Connect
- [ ] 在 App Store Connect 填写此文档中的文案和截图
- [ ] 提交审核
