隐私政策

最后更新：2026 年 7 月 1 日

「今日微笑」（以下简称"我们"）深知隐私对您的重要性。本隐私政策说明我们如何收集、使用和保护您的信息。

我们不收集的信息

打卡数据：您的微笑状态、心情原因、照片等所有打卡数据，仅存储在您的手机本地。我们不会收集、上传或访问这些数据。

使用行为：我们不追踪您的使用行为，不使用任何分析工具或埋点 SDK。

设备信息：通知推送由系统级服务处理，我们不会收集您的设备标识符或位置信息。

我们使用的服务

账户认证：您注册时提供的邮箱地址，仅用于 Supabase Auth 提供的身份认证和密码找回服务。Supabase 的隐私政策见其官方网站。

绝不用于广告：我们不会将任何信息用于广告投放、营销分析或出售给任何第三方。本 App 不含任何广告 SDK。

数据安全

所有打卡数据仅存储在您的设备本地，不经过任何服务器。认证通信使用 HTTPS 加密传输。

您的权利

由于所有打卡数据仅存储在您的设备本地，卸载 App 即彻底清除所有数据。您也可以随时在 App 内手动删除单条记录。

儿童隐私

本 App 不针对 13 岁以下儿童。我们不收集任何用户的个人信息，因此也不涉及儿童隐私数据问题。

政策更新

本隐私政策可能不时更新，重大变更会通过 App 内通知告知您。

联系我们

如有任何隐私相关问题，请通过 GitHub Issues 联系我们：github.com/Darinyazanr/smile-app/issues
