隐私政策

最后更新：2026 年 7 月 1 日

「今日微笑」（以下简称"我们"）深知隐私对您的重要性。本隐私政策说明我们如何收集、使用和保护您的信息。

我们收集的信息

账户信息：您注册时提供的邮箱地址，仅用于身份认证和密码找回。

打卡数据：您记录的微笑状态、心情原因、照片等，存储在您的个人账户下。

设备信息：仅用于推送通知功能，不会上传至服务器。

我们如何使用信息

提供核心服务：保存您的打卡记录，展示统计数据和日历视图。

账户管理：邮箱用于登录认证和密码找回，我们不会发送营销邮件。

绝不用于广告：我们不会将您的数据用于广告投放、营销分析或出售给任何第三方。

数据安全

所有数据传输使用 HTTPS 加密。认证和数据库服务由 Supabase 提供，采用行业标准安全措施。照片存储使用加密存储服务。

您的权利

您可以随时在 App 内导出或删除您的全部打卡数据。删除账户后，所有关联数据将被永久清除，无法恢复。

儿童隐私

本 App 不针对 13 岁以下儿童，我们不会故意收集儿童的个人信息。

政策更新

本隐私政策可能不时更新，重大变更会通过 App 内通知告知您。

联系我们

如有任何隐私相关问题，请通过 GitHub Issues 联系我们：github.com/Darinyazanr/smile-app/issues
